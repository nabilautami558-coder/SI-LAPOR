# SI-LAPOR

## Aplikasi Pelaporan Fasilitas Sekolah

SI-LAPOR adalah aplikasi berbasis Android yang digunakan untuk melaporkan kerusakan atau masalah fasilitas sekolah agar dapat ditindaklanjuti dengan lebih mudah.

### Fitur
- Mengirim laporan kerusakan fasilitas sekolah.
- Menambahkan deskripsi laporan.
- Menggunakan lokasi GPS.
- Mengunggah foto laporan.
- Melihat riwayat laporan.
- Memantau status laporan.
- Mengelola laporan melalui halaman admin.

### Teknologi
- MIT App Inventor
- PHP
- MySQL
- Laragon

### Isi Repository
- `SI_LAPOR.aia` — project MIT App Inventor.
- `SI_LAPOR.apk` — aplikasi Android.
- File PHP — backend dan halaman admin SI-LAPOR.

### Catatan
Project ini dibuat untuk tugas sekolah Pengembangan Perangkat Lunak dan Gim (PPLG).
